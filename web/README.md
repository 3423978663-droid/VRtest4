# 阅读背词 · 网页版

拍照/手机扫码上传英语阅读题照片 → 自动 OCR 识别英文单词 → 点击单词查词（本地词库（中考/高考/雅思）优先，秒出音标/词性/中文释义；可联网补充例句）→ 加入「本次收获」→ 一键导出排版美观的 PDF（只含单词/音标/词性/中文翻译）。

> 无需数据库，单词只存在当前网页内存里，刷新即清空。

## 本地启动（零依赖，无需 npm install）
本机已安装 Node.js 即可：

```bash
cd web
node server.js
# 或者
npm start
```

启动后终端会打印访问地址：
- 本机访问：`http://localhost:3000`
- 局域网访问：`http://<你电脑的IP>:3000`（手机扫码上传用这个）

用浏览器打开 `http://localhost:3000` 即可使用。

## 使用流程
1. **上传照片**：点「上传照片（可多选）」，可以一次选择多张英语阅读题照片；也可以直接把图片拖到页面里。
2. **手机扫码上传**：点「手机扫码上传」→ 手机扫一扫 → 拍照/选图上传 → 电脑端自动收到并识别。
   - 本地运行版：手机和电脑需连**同一个 Wi-Fi**。
   - 在线分享版（Netlify）：任何网络都可以，照片暂存云端，24 小时后自动清理。
3. **多图切换**：图片会在底部以缩略图排列，可随时点击切换；点缩略图右上角「×」可删除，点「＋」继续添加。
4. **点词查词**：照片识别完成后，点击照片里的英文单词，弹出单词卡片（本地词库秒出音标/词性/中文释义）。如需英文释义和例句，点卡片里的「联网补充例句/英文释义」。
5. **加入本次收获**：在单词卡片里点「加入本次收获」。
6. **导出 PDF**：右上角点「导出 PDF」，在弹出的打印窗口里选择「另存为 PDF」保存。

## 注意事项
- 手机扫码上传：本地版要求**手机和电脑在同一 Wi-Fi**；在线版无此限制。
- 首次识别会自动联网下载 OCR 模型，请保持联网。
- 查词采用「**本地词库优先 + 联网兜底**」：本地已内置中考/高考/雅思约 6400 词（`public/data/dict-3500.json`），命中即秒回；本地没有的词才走免费联网接口（Free Dictionary + MyMemory），本地版会缓存在 `web/data/dict-cache.json`。
- 本次收获**不持久化**，刷新页面会丢失；有未导出的单词时，关闭页面前会弹提醒。
- 上传的照片会保存在 `web/data/<会话ID>/` 下。

## 目录结构
```
web/
  server.js        本地服务（Node 内置模块，无依赖）
  package.json     npm start 脚本
  public/
    index.html     主页面
    app.js         前端逻辑（OCR / 本地查词 / 收集 / 导出）
    style.css      界面与打印排版
    upload.html    手机扫码上传页
    data/
      dict-3500.json   本地词库（中考/高考约 3900 词）
  data/            运行时数据（上传照片、联网词典缓存）
  netlify/
    functions/     Netlify 云函数（联网查词代理、能力信息）
  scripts/
    build-dict.py   重新生成本地词库（可选，通常无需运行）
```

## 常见问题
- **手机扫码打不开页面**：确认手机和电脑连的是同一个 Wi-Fi；并在 macOS「系统设置 → 隐私与安全性 → 防火墙」里允许 Node 接受传入连接（首次运行可能会弹窗）。
- **点词没反应 / 识别不出**：等识别状态变成「已识别 N 个词」后再点；或用「手动查词」。
- **查词失败**：本地词库没有这个词时需要联网；免费词典接口偶尔不稳定，可重试或换用「联网补充例句/英文释义」。
